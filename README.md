# Flask App CI/CD Pipeline

## Overview
This repository contains a Flask web application with automated CI/CD pipelines
using both Jenkins and GitHub Actions.

## Project Structure
```bash
flask-app/
│── app.py
│── requirements.txt
│── .env
│── templates/
│── .github/workflows/deploy.yml
│── start_flask.sh
│── test_app.py
│── Jenkinsfile
```
